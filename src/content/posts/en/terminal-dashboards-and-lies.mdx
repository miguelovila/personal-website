A terminal dashboard has the power to make any habit feel disciplined. That is both the appeal and the problem.

## The dashboard

```bash
printf 'posts=%s projects=%s links=%s\n' 15 10 243
```

The numbers look official. The trick is remembering that official-looking numbers can still be nonsense.

## The useful lie

A dashboard can be useful when it makes the next action obvious. It becomes theater when it mainly proves that a dashboard exists.

| Metric       | Useful question        | Bad habit                            |
| ------------ | ---------------------- | ------------------------------------ |
| Draft count  | What needs a decision? | Feeling productive by counting dust. |
| Broken links | What needs fixing?     | Rechecking without fixing.           |
| Build time   | Did something regress? | Optimizing a tiny site into sadness. |

## The exit

If a number does not change what I do next, it probably belongs in a log, not above the fold.
