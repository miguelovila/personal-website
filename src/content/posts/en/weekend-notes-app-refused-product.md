The weekend notes app did one thing well: it let me write a note, tag it, and find it later. Naturally, I tried to ruin it.

## The first temptation

Sync. Then sharing. Then templates. Then a tiny analytics view that would definitely be useful one day.

## The stop point

I wrote down the rule that saved the project:

```txt
If the feature helps me publish the note, build it.
If it helps me talk about maybe publishing the note, park it.
```

## The fake product table

| Idea            | Built?         | Why                                  |
| --------------- | -------------- | ------------------------------------ |
| Tags            | Yes            | They make old notes findable.        |
| Sync            | No             | Export was enough for the prototype. |
| Public profiles | Absolutely not | The app was already looking smug.    |

## The lesson

A side project can be complete because it stayed small. That is not failure. That is taste doing maintenance.
