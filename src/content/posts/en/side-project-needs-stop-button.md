## The stop button

Some projects need a backlog. Some need a README update. Some need the dignity of being archived.

## The checklist

- Has the project taught the thing it needed to teach?
- Is the next feature useful or just emotionally loud?
- Would maintenance feel like care or punishment?
- Can the project be left in a state that explains itself?

## The archived state

Archived should not mean abandoned in shame. It can mean the work reached its natural size.
