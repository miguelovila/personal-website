Search looks like one input. It is usually a dozen tiny promises: the right language, useful excerpts, a good empty state, and no surprise navigation.

## The content boundary

For this site, search should index the same things the site publishes. Drafts and future posts should not leak into results just because the search build found the files.

```ts
const searchable = entries.filter((entry) => {
  return !entry.data.draft && entry.data.publishedDate <= new Date();
});
```

## The language boundary

Portuguese results should stay Portuguese. English results should stay English. That sounds obvious until a single global index returns everything.

## The failure state

If the index fails to load, the modal should still feel owned by the site. A plain error and useful archive links are better than a spinner that has made a lifestyle choice.
