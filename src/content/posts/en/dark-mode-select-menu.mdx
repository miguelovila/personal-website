The fastest way to spot a fake design system is to open the one control nobody styled. Native select menus have a dramatic sense of timing.

## The symptom

The page is dark. The modal is dark. The input is dark. Then the dropdown opens and suddenly the operating system has joined the design review.

## The playground

<ThemeTokenPlayground client:load />

## The fix pattern

The implementation should make the boring path beautiful: input, select, button, dialog, sheet, dropdown. Those are not edge cases. They are the interface.

```tsx
<Select value={theme} onValueChange={setTheme}>
  <SelectTrigger>
    <SelectValue />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="system">System</SelectItem>
  </SelectContent>
</Select>
```

## The part I keep forgetting

Focus states need to be visible in both themes. Pretty is not finished until keyboard users can see where they are.
